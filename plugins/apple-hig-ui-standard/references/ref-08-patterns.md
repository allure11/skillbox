# 交互模式（Patterns）

> 来源：Apple HIG《模式》。模式是跨组件的组合性设计解法。

## 一、模态化（Modality）详解

模态化是在**单独的专用模式**中呈现内容的设计技术，可阻止与父视图交互，且需要确切操作才能关闭。

适用场景：
- 确保用户接收关键信息，并在必要时对其操作
- 提供选项让用户确认或修改最近的操作
- 帮助用户执行明确的小范围任务，同时不忘记之前的环境
- 向用户提供沉浸式体验，或帮助其专注于复杂任务

呈现载体：所有平台都可显示**提醒**；各平台还定义**活动视图**、**表单**、**确认对话框**/**操作表单**。
iOS/iPadOS/macOS 倾向用表单或弹出窗口；iPadOS/macOS/visionOS 还可能使用单独窗口。

### 最佳实践
- **仅在有明确益处时才以模态化方式呈现内容**【强制】：模态体验会将用户带离当前环境且需要操作才能关闭，
  只有模态化有助于用户专注、或有助于用户作出影响其内容/设备的选择时才使用。
- **致力于保持模态任务简短和精炼**：任务过于复杂时，用户可能忘记进入模态视图时暂停的任务
  （尤其模态视图挡住了之前环境时）。
- **避免让模态体验看起来像 App 内的 App**：模态任务内呈现视图层级尤其会使用户忘记如何回溯步骤；
  若模态任务必须包含子视图，**提供浏览层级结构的单一路径**，
  并**避免包含可能被误认为关闭按钮的按钮**。
- **考虑为深度内容或复杂任务使用全屏幕模态样式**：填满窗口或显示屏的模态最大程度减少干扰，
  适合呈现视频/照片/相机视图，或支持标记文稿、编辑照片等多步骤任务。
  visionOS App 在共享空间中运行时全屏模态填满窗口，转入全空间时可变成更有沉浸感的体验。
- **始终向用户提供关闭模态视图的明显方式**【强制】：
  - iOS/iPadOS/watchOS：用户通常期望在**顶部工具栏**找到按钮或**向下轻扫**；
  - macOS/tvOS：用户期望在**主内容视图**中找到按钮。
- **必要时通过在关闭前获得确认来帮助用户避免数据丢失**：
  无论使用关闭手势还是按钮，若关闭可能导致用户生成的内容丢失，必须解释情况并提供解决方式
  （如 iOS 中呈现包含保存选项的操作表单）。
- **让模态视图的任务易于识别**：提供为任务命名的标题（或描述任务、提供引导的其他文本），
  帮助用户保持其在 App 中的位置感。
- **让用户关闭一个模态视图，然后呈现另一个模态视图**【强制】：
  同时让用户看到多个模态视图会造成视觉混乱；呈现多个模态会增加认知负荷（尤其相互遮挡时）。
  **虽然提醒可以显示在所有其他内容之上，但绝不应同时显示多个提醒。**

## 二、模式主题索引

以下为 HIG 定义的全部模式及其核心用途（详细规则请按需查阅官方对应页面）。

| 模式 | 用途与核心关注点 |
|---|---|
| **图表化数据**（Charting data） | 用图表呈现数据时保证准确、可读、可访问（不依赖颜色、提供无障碍描述） |
| **协作与共享**（Collaboration and sharing） | 多人协作与内容分享的权限、可见性、邀请流程设计 |
| **拖放**（Drag and drop） | 拖放手势的启动、反馈、落点提示与替代方案 |
| **输入数据**（Entering data） | 表单与数据录入：减少输入负担、提供默认值与校验反馈 |
| **反馈**（Feedback） | 反馈强度与信息重要性匹配（详见 `ref-07-motion-feedback.md`） |
| **文件管理**（File management） | 文件的创建、保存、打开、版本与位置管理 |
| **全屏显示**（Going full screen） | 全屏（非模态）体验的进入退出与状态保持 |
| **启动**（Launching） | 启动速度、启动画面与首屏内容呈现 |
| **实时查看类 App**（Live-viewing apps） | 相机、AR 等实时视图类体验的界面叠加与控件布局 |
| **加载**（Loading） | 占位符、进度指示符与后台加载（详见 `ref-07-motion-feedback.md`） |
| **账户管理**（Managing accounts） | 登录、注册、账户切换与注销的流程与安全 |
| **通知管理**（Managing notifications） | 权限请求时机、通知分级与用户可控性 |
| **模态化**（Modality） | 模态场景判定、关闭方式与嵌套禁忌（见上文详解） |
| **多任务**（Multitasking） | 分屏、多窗口、画中画下的布局与状态适配 |
| **提供帮助**（Offering help） | 帮助入口、上下文相关帮助与工具提示 |
| **引导与上手**（Onboarding） | 首次使用引导：可跳过、渐进式、避免一次性灌输 |
| **播放音频**（Playing audio） | 音频播放控制、后台播放与打断处理 |
| **触感反馈**（Playing haptics） | 触感类型与语义匹配，作为音频/视觉提示的补充 |
| **播放视频**（Playing video） | 视频播放器控件、画中画、字幕与全屏 |
| **打印**（Printing） | 打印设置与预览流程 |
| **评分与评论**（Ratings and reviews） | 请求评分/评论的时机与频率控制（避免打断） |
| **搜索**（Searching） | 搜索入口、建议、结果呈现与无结果处理 |
| **设置**（Settings） | 设置的分层、默认值、即时生效与系统设置的关系 |
| **撤销与重做**（Undo and redo） | 可撤销操作的范围、历史与用户预期 |
| **体能训练**（Workouts） | watchOS 体能训练类 App 的界面与数据呈现 |

> 需要用哪个模式时，先查本表定位，再到官方页面获取完整规则，不要凭经验臆断。
